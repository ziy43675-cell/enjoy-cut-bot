# 帳號申請手冊（給弟弟）

哥哥已經把程式寫好了，你只要照這份把帳號辦好、把幾組資料交給哥哥。**全部用同一個店專用 Gmail**，不要用你的私人帳號，以後比較好交接。

大約需要 1 小時。過程中遇到跟這份說明畫面不一樣的地方，截圖傳給哥哥就好。

---

## 第 1 步：申請店專用 Gmail

1. 到 Gmail 申請新帳號，例如 `店名salon@gmail.com`。
2. 密碼記好，並開啟兩步驟驗證（綁你的手機）。

✅ 交給哥哥：這個 Gmail 地址（密碼不用給）

---

## 第 2 步：申請 LINE 官方帳號

1. 手機或電腦搜尋「LINE 官方帳號」，進入 LINE for Business 網站 → 建立帳號。
2. 用**你自己的 LINE** 登入。
3. 填寫：帳號名稱（店名）、電子郵件（填第 1 步的 Gmail）、業種選「美容、美髮」相關。
4. 方案用免費的「輕用量」就好，不用付錢。

### 開啟 Messaging API

5. 進入 LINE Official Account Manager（官方帳號管理後台）→ 右上角「設定」→ 左邊「Messaging API」→ 按「啟用 Messaging API」。
6. 要你建立「服務提供者（Provider）」，名稱填店名即可。

### 回應設定

7. 左邊選「回應設定」：
   - 聊天：**關閉**
   - 加入好友的歡迎訊息：**關閉**
   - 自動回應訊息：**關閉**
   - Webhook：**開啟**

### 把哥哥加成管理員

8. 「設定」→「權限管理」→「新增成員」→ 權限選「管理員」→ 產生邀請連結 → 把連結傳給哥哥。

---

## 第 3 步：LINE Developers（拿密鑰）

1. 到 LINE Developers 網站，用**同一個 LINE 帳號**登入。
2. 點第 2 步建立的 Provider → 點裡面那個 channel。
3. 「Basic settings」分頁往下找 **Channel secret**，複製。
4. 「Messaging API」分頁最下面 **Channel access token** → 按「Issue」→ 複製。
5. 把哥哥加成員：回到 Provider 頁面 →「Roles」→「Invite by email」→ 輸入哥哥的 email，權限選 Admin。

✅ 交給哥哥（用私訊，不要貼在群組）：
- Channel secret
- Channel access token

⚠️ 這兩組等於機器人的鑰匙，不要給其他人。

---

## 第 4 步：Firebase（資料庫）

1. 用店專用 Gmail 登入 Firebase 主控台 →「新增專案」，名稱填店名。
2. Google Analytics 可以關掉。
3. 左邊「建構」→「Firestore Database」→「建立資料庫」→ 位置選 `asia-east1（台灣）` → 選「正式版模式」。
4. 左上齒輪「專案設定」→「服務帳戶」→ 按「產生新的私密金鑰」→ 會下載一個 `.json` 檔。
5. 把哥哥加成員：「專案設定」→「使用者和權限」→「新增成員」→ 輸入哥哥的 email，角色選「擁有者」。

✅ 交給哥哥：那個 `.json` 檔（私訊傳，不要公開）

---

## 第 5 步：GitHub

1. 用店專用 Gmail 申請 GitHub 帳號。
2. 告訴哥哥你的 GitHub 帳號名稱，哥哥會把程式放上來，或請你把他加成協作者。

✅ 交給哥哥：GitHub 帳號名稱

---

## 第 6 步：Railway（放程式的主機）

1. 到 Railway 網站 → 用第 5 步的 GitHub 帳號登入。
2. 需要綁一張信用卡。費用大約每月 5 美元（Hobby 方案），扣款會用這張卡。
3. 登入後告訴哥哥，由哥哥接手部署（或照哥哥遠端指示操作）。

✅ 交給哥哥：已完成登入的通知

---

## 最後：交給媽媽

哥哥部署完成後會給你一個「老闆密碼」：

1. 用**媽媽的手機**加入店的 LINE 官方帳號好友。
2. 在聊天室傳：`#老闆 密碼`（例如 `#老闆 8888`）。
3. 下方選單變成六格的老闆版，就完成了。
4. 員工加好友後按「申請成為員工」，媽媽手機會收到通知，按「核准」即可。
